# 02 · 영업 파이프라인·전환 분석

**영업 분석 PoC · 디자인·개발 전담 · 2026년 4월 조회** · Tableau

> 바이어 발굴은 어느 단계까지 진행되었는가?

대시보드 디자인과 개발을 전담했습니다. 리드에서 컨택·미팅·샘플·거래처 전환까지의 흐름을 정리하고, 단계별 달성률과 담당자별 현황을 비교하도록 구성했습니다.

[![영업 파이프라인·전환 분석 — 마스킹한 화면](assets/luvum.png)](assets/luvum.png)

*이미지를 선택하면 큰 화면으로 볼 수 있습니다. 회사명·로고·실제 수치·상세정보는 마스킹했으며, 차트 형태와 배치는 유지했습니다.*

## 프로젝트 맥락

**Tableau 영업지원 PoC | 대시보드 기획 · 디자인 · 개발 · 데이터 관리 기준 정리**

해외 B2B 영업 현황을 매출 목표·실적과 신규 바이어 발굴 단계로 나눠 확인할 수 있도록 Tableau 대시보드를 구성했습니다. 기존 엑셀 보고 자료를 바탕으로 화면 기획안을 구체화하고, 대시보드 디자인과 개발을 담당했습니다.

기획안에는 매출 KPI·월별 추이·국가별 비교와 신규 바이어 영업 단계가 함께 포함돼 있습니다. 이 페이지의 기존 마스킹 이미지는 영업 파이프라인 화면을 보여줍니다.

[수행 내용과 산출물 정리](../project-experience.md#luvum)

## 화면 구성

### 1. 디자인·개발 전담

메뉴와 KPI 요약, 단계별 달성률, 담당자 비교 영역의 디자인과 개발을 직접 담당했습니다.

### 2. 진행 단계의 시각화

리드부터 거래처 전환까지의 현황을 상단에 두고, 단계별 KPI는 게이지로 표현했습니다.

### 3. 담당자별 비교

월별 달성률 추이와 담당자별 진행 현황을 함께 배치해 단계별 차이를 살펴봅니다.

**담당 역할:** 디자인·개발 전담

2026년 4월로 조회한 화면의 상단 분석 영역입니다. 바이어 연락처 상세 목록은 제외했습니다.

**주요 구성:** 디자인·개발 전담 / 단계별 KPI / 담당자 비교
