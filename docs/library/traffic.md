# 02 · 서비스 트래픽 분석

**마케팅·서비스 분석 샘플** · Tableau

> 방문자는 어디에서 유입되고, 어떻게 이용하는가?

방문·세션·이탈률을 요약하고 채널, 시간대, 지역, 기기별로 서비스 이용 현황을 살펴보는 화면입니다.

[![서비스 트래픽 분석 — 마스킹한 화면](assets/traffic.png)](assets/traffic.png)

*이미지를 선택하면 큰 화면으로 볼 수 있습니다. 회사명·로고·실제 수치·상세정보는 마스킹했으며, 차트 형태와 배치는 유지했습니다.*

## 화면 구성

### 1. 이용 현황 요약

사용자 수, 세션, 세션당 페이지 수, 평균 세션 시간, 이탈률을 함께 배치합니다.

### 2. 유입과 행동의 분해

일별 추이와 채널별 분포를 비교하고, 시간대별 히트맵으로 이용 패턴을 확인합니다.

### 3. 세부 조건의 비교

지역·키워드·기기를 나누어 전체 지표만으로 보이지 않는 차이를 살펴봅니다.

**주요 구성:** 행동 지표 / 채널 분석 / 히트맵
